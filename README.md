# 南投縣立南投國民中學 115學年度 社團點名系統

> **南投國中 115 學年度 第一學期 各社團點名管理線上系統**  
> 🌐 **線上系統網址**：[https://yaoshuchin.github.io/1151118-nantou-club-rollcall/](https://yaoshuchin.github.io/1151118-nantou-club-rollcall/)  
> 🔒 **校園門禁管制密碼**：`nato`  
> ⏰ **固定活動時段**：**每週二 第 7 節、第 8 節**  

---

## 📖 系統簡介

本系統專為南投縣立南投國民中學 115 學年度社團活動量身打造，將全校 13 個社團（含國樂團/集訓隊）共 259 位社員名冊完整數位化。

指導教師或社長、幹部可直接使用手機、平板或電腦進行現場點名，支援離線快取、自動儲存（LocalStorage）、快速循環切換出席狀態、一鍵全員出席、第8節自動同步第7節、多格式報表匯出（Excel / CSV）及標準 A4 紙本友善列印。

---

## 🎯 核心功能特色

### 1. 🔒 門禁密碼管制 (`nato`)
- 具備校園系統門禁機制，防範非校內人士誤觸更動。
- 通行碼支援不分大小寫驗證，可記住在瀏覽器中。
- 提供右上角「🔒 鎖定 / 登出」一鍵退出功能。

### 2. 📅 嚴格週二日期管制 (Tuesday Strictly Enforced)
- 點名單日期**一律固定為每週二**，涵蓋第 7 節與第 8 節。
- 內建學期週二日程下拉快速切換（10/06、10/13、10/20、10/27、11/03、11/10 等）。
- 支援自訂任意日期：若使用者選擇非週二日期，系統自動依校規校正至最接近之週二，杜絕非上課日誤點。

### 3. 📝 智慧點名與批次操作（出席與缺席）
- **⚡ 快速記缺席輸入列（支援 10306 / 70306 代碼快速標記）**：
  - 專為現場點名設計的快捷輸入框，支援輸入「年班座號代碼」：
    - 一年 3 班 6 號可輸入 `10306` 或 `70306`（亦支援 `7036`、`703-6`）
    - 二年 4 班 10 號可輸入 `20410` 或 `80410`
    - 三年 9 班 7 號可輸入 `30907` 或 `90907`
  - 支援同時輸入多筆學生（逗號或空白隔開），按 **Enter** 鍵立即將該生標記為【缺席 (X)】並閃爍醒目定位！
  - 支援選擇「兩節皆缺席」、「僅第7節缺席」或「僅第8節缺席」。
  - 具備跨社團智慧檢索：若輸入之學生屬於其他社團，系統會主動提示並支援一鍵切換。
- **二元點名模式**：點名規則精確分為「出席 (O)」與「缺席 (X)」，點擊按鈕直接二元快速切換，操作極簡直覺。
- **🎓 資優鑑定生特殊註記（第7節免出席）**：
  - **201 班 陳揚宗**（羽球社 23 號）
  - **204 班 陳紅妘**（桌遊團康社 10 號）
  - 兩位學生標註專屬紫色「資優生 (第7節免出席)」徽章，第 7 節自動預設「免出席」，備註欄自動加註「資優鑑定生不用上第7節，不用出席」，不列入第 7 節缺席計算；第 8 節正常出席。
- **🟢 一鍵全員出席**：單鍵將全體社員第 7 節與第 8 節直接標記為出席 `O`（資優生第7節自動保持免出席）。
- **🔄 第8節同步第7節**：第 7 節點名完成後，一鍵直接鏡像複製到第 8 節（資優生第8節自動維持出席）。
- **💬 違規與紀律備註**：即時填寫個別學生違規事項、器材借還或優良表現，失焦自動存檔。
- **👤 人員異動管理**：支援即時新增社員、修改姓名座號及幹部與資優生身份註記。

### 4. 📊 即時出席率儀表板
- 應到人數、實到人數、缺席人數、請假人數即時動態統計。
- 第 7 節與第 8 節分節出席率及綜合進度條。

### 5. 📤 全方位報表匯出與備份
- **匯出本社 Excel (`.xlsx`)**：輸出與學校格式 100% 相容的單社團完整點名單。
- **匯出全校社團活頁簿 (`.xlsx`)**：一鍵產生包含全校 13 社團完整標頭與出席數據之多工作表 Excel 總簿。
- **匯出 CSV (`.csv`)**：UTF-8 BOM 編碼，相容校務行政系統與 Excel 直接開啟無亂碼。
- **🖨️ 友善紙本列印 (Print to A4 / PDF)**：專用列印樣式，自動隱藏網頁按鈕，排版出包含學校表頭、名冊表格及指導教師/社長/訓育組簽章欄之正式單據。
- **💾 JSON 備份與還原**：隨時備份全校資料庫或從備份檔案快速復原。

## 🛠️ 技術架構

- **前端核心**：純純原生 HTML5、CSS3、JavaScript (ES6+)
- **樣式引擎**：Tailwind CSS (現代極簡響應式介面)
- **圖示庫**：FontAwesome 6
- **試算表處理**：SheetJS (`xlsx.full.min.js`)
- **離線儲存**：Web Storage API (LocalStorage 隨打隨存)
- **部署託管**：GitHub Pages 靜態安全託管
